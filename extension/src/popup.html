Краткая выжимка форума

1. Проверка страницы

проверяем…

Откройте тему форума в этой вкладке.

Текст внутри раскрываемого блока берётся, если он уже есть в коде страницы; внешние ссылки и файлы автоматически не открываются.

«Удалить только неправильные записи» убирает очевидные пункты меню и сохраняет точку отсчёта. Кнопка ниже удаляет все посты, отчёты, Q&A и точку отсчёта этой темы. «Удалить всю базу» удаляет все темы, посты и отчёты без возможности отмены. Перед удалением при необходимости скачайте всю базу для редактора. CAPTCHA, вход и 403/429 не обходятся.

2. Собрать сообщения

точка отсчёта не создана

«Загрузить страницы от открытой» — откройте нужную старую страницу темы и нажмите эту кнопку: расширение пойдёт назад от неё и добавит старые сообщения в базу, их можно отдать ИИ отдельным пакетом. «Запомнить это место» — безопасное начало без загрузки старой истории. В обычной проверке расширение само найдёт последнюю страницу темы по сохранённой точке и пойдёт назад до неё.

3. Получить выжимку через ИИ

нет данных
Форматы одного файла

Единый файл содержит сразу инструкции для ИИ и все сообщения. Режим с разбивкой нужен только для очень большого объёма, когда ИИ не принимает всё целиком. Кнопка «Скачать всю базу» сохраняет отдельные JSON и Markdown для редактора и резервной копии — без AI-промпта.

4. Найти сохранённое

только на этом компьютере

Введите любое слово и нажмите «Найти». Расширение ищет в тексте постов, сохранённых сводках и Q&A.

6. Диагностика ошибки

для разработчика

Если сбор остановился, нажмите кнопку. Расширение сохранит технический лог с URL, классами и примерами HTML. Пришлите мне файл, если понадобится исправление.

7. Сохранённые выжимки

ищите здесь

После импорта ответ ИИ не исчезает: его краткая версия и полный текст хранятся в расширении. При запущенном companion их также видно в локальной веб-панели.
